=== ZK Clear-Signing VK Manifest (firmware build artifact) ===
Built from secure/data/vks.json by `cargo run -p dbgen`.

The wallet's secure world holds only the Merkle ROOT below; the
full VK pool lives in non-secure firmware rodata. At sign time the
non-secure world supplies (vk_bytes, merkle_proof) and the secure
world re-derives the leaf hash from (chain_id, contract, vk_bytes)
and walks the proof up to this root.

Merkle root (VK_DB_ROOT) = 9a210e825cbe45cd537c6148f86afded2d47d0380ed50cc6c7d55dde41e730d7

This file is a build-traceability artifact. It records which
(chain_id, contract, sha256(vk)) triples were folded into the
VK_DB_ROOT above, so a release reviewer can diff it against the
previous release and confirm nothing unexpected was added.
The trust chain is entirely offline: firmware-signing key →
VK_DB_ROOT in secure flash → Merkle proof → Groth16 verification.
No on-chain comparison is performed, ever.
