IDENTITY CALCULATOR, VALIDATED (scratch/encode-compat/inputs_id.sh)
Earlier in this arc I computed INPUTS_SHA256 on the HOST without LC_ALL=C and produced
TWO wrong-but-plausible values (ddd456c5.., 2bcbb7ce..).  The hash is collation-sensitive.
The script now reproduces the gate's own printed value EXACTLY for an unchanged tree:

    gate printed : e14a1422f9713edfbe10a6c316ee12e3
    script       : e14a1422f9713edfbe10a6c316ee12e3   MATCH

It is therefore trustworthy for computing the identity of the NEXT tree state without
burning a full gate run to discover it.  It is self-validating by construction: if it ever
stops reproducing the gate's printed value on an unchanged tree, do not trust it -- take
the gate's value.  It lives in scratch/encode-compat/, which is NOT in the hashed set, so
adding it does not perturb the identity it computes.
