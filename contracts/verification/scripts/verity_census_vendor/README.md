# Verity census kernel replay

`VerityCensusReplay.lean` is an unmodified copy of
`Lean4Checker/Replay.lean` from the locally available upstream
`leanprover/lean4checker` commit `0531c5e62c6bbc21af6c8b4adc2a16d201bf8b65`
(tag `v4.22.0`). Its Apache-2.0 license is included.

The collector replays candidate constants into a separate environment imported
only from the pinned Lean distribution, using the kernel directly. Project
constructors and recursors are compared with the ones regenerated by the
kernel. This closes unchecked declaration injection; an ordinary `.olean`
import, even at trust level zero, does not perform that replay.

The upstream implementation skips unsafe and partial declarations. The gate
rejects every unsafe project declaration and pins the five existing partial
compiler helpers separately. Those helpers receive a census, not a kernel replay.
The Lean kernel/stdlib remain trusted; this is not an independent kernel implementation.
