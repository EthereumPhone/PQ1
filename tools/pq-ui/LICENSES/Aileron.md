# Aileron (Regular, SemiBold)

Designer: Sora Sagano (TipoType / dot colon). Published upstream as **CC0 1.0
Universal (public domain dedication)** — no attribution required, embedding in
firmware permitted.

The upstream PQ-UI repository ships `pq1/assets/OFL.txt` next to these fonts,
but that file is the SIL OFL text for *Chakra Petch* (an unrelated font left
over from an earlier mockup); it does not license Aileron and was dropped from
this vendored copy. Pin the CC0 text from the font's own distribution before a
release image ships (`secure/assets/ui-px/LICENSES/` is the firmware-side copy).
