Selector decoding (Phase 2 / 2b)

For the device to render decoded args (arg 0 uint256: 1000) instead of a raw hex word dump, the calldata's 4-byte selector needs a known text_sig. Two paths:
  • Curated: load selectors_db.bin (companion-stub artifact). Vendor-attested name; device shows ! BLIND SIGN banner.
  • Self-attest: companion supplies (selector, text_sig) directly; firmware verifies keccak256(text_sig)[..4] == selector + ABI shape match. Device shows louder ! UNVERIFIED banner.
Both are mutually exclusive per call. selectors_db.bin is ~775 KB — pick it via the file input below; the page reads + parses it locally and never sends the blob over the wire.
